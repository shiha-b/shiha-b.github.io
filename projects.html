UAV & Flight Control Systems

Thesis Project

Low-Cost Dual-Core Flight Controller for Quadcopter

Designed and developed a custom flight controller from scratch for quadcopter applications. Features dual-core processing, sensor fusion, PID stabilization, and real-time telemetry. The system was rigorously tested under partial propeller disturbance conditions to evaluate performance, reliability, and fault tolerance in challenging flight scenarios.

Research Impact

Demonstrates cost-effective flight control solutions and establishes performance benchmarks for UAV systems under adverse conditions.

Extended & Unscented Kalman Filters for Low-Cost Quadcopter

Developed Extended Kalman Filter (EKF) and Unscented Kalman Filter (UKF) implementations in Python for sensor fusion in UAV systems. Created versions for both 6 DOF and 9 DOF IMU configurations, focusing on accurate state estimation and attitude determination for flight control applications.

Algorithm Implementation

Advanced sensor fusion algorithms ready for integration into flight control systems for improved UAV stability and navigation accuracy.
